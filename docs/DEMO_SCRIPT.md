# Final Demo Script

## Customer
1. Open Home and show categories/products.
2. Search and filter a product.
3. Open Product Details and reviews.
4. Add the product to Cart and change quantity.
5. Open Checkout and show address/payment/reward points.
6. Place the order.
7. Open Order Details and Live Tracking.

## Seller
1. Login with seller account.
2. Show dashboard sales/order/product statistics.
3. Open Products and edit stock/price.
4. Open Orders and change status.
5. Move courier location and return to customer tracking.

## Admin
1. Login with admin account.
2. Show dashboard and platform volume.
3. Manage users and seller verification.
4. Manage products/categories/orders.
5. Show coupons and homepage banners.
6. Show newsletter subscribers/campaigns.
