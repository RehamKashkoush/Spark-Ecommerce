# Suggested Demo Flow

1. Open the storefront and demonstrate language switching.
2. Search products, filter by category/price, open product details, and show reviews.
3. Login with a customer account and demonstrate wishlist, profile, addresses, payment details, notifications, loyalty points, and referrals.
4. Add products to cart and show promo code and reward-points usage.
5. Demonstrate the available checkout methods without exposing real credentials.
6. Open Orders and demonstrate order details and live tracking.
7. Login as Seller and show dashboard, products, inventory, order processing, courier movement, and payouts.
8. Login as Admin and show users, sellers, products, categories, orders, coupons, banners, newsletter campaigns, referrals, and loyalty management.
9. Show the backend API structure and MongoDB models.
10. Finish by showing the technology stack and deployment environment variables.
